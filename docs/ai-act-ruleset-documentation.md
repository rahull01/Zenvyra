# AI Act Ruleset Documentation

## Overview

The AI Act ruleset is versioned using `AiActRuleCatalog` and `AiActRuleCatalogFactory`. The current version is `V2026_07`.

## Risk Levels

- **PROHIBITED**: Banned AI practices (Article 5)
- **HIGH_RISK**: High-risk AI systems (Annex III)
- **LIMITED_RISK**: Limited-risk AI systems (Article 50)
- **MINIMAL_RISK**: Minimal-risk AI systems (Article 4)

## Obligations

Each risk level maps to specific obligations:
- Prohibited: None (banned)
- High-risk: Conformity assessment, risk management, data governance, technical documentation, transparency, human oversight, accuracy, robustness, cybersecurity
- Limited-risk: Transparency notices (Article 50)
- Minimal-risk: AI literacy (Article 4)
